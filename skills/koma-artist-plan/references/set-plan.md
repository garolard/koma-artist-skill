# Set plan format

Use a readable Markdown document, preserving user decisions and distinguishing suggested, approved, and unresolved choices. Record set title and code if known; for each planned panel record slot, source path, proposed title, shape, rarity, crop intent and any issue. Record cover source, three preview slot numbers, missing assets, counts and review status. Paths are local and relative to the plan where practical. Do not imply suggestions are artist-approved. If details cannot be inspected, mark them unknown. Keep this document current when the artist revises decisions.
