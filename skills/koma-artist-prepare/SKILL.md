# koma-artist-prepare

Read [KOMA reference](references/koma.md) and [set plan format](references/set-plan.md). Treat the artist as the final decision-maker. Do not claim to have seen images you cannot inspect; distinguish visual judgment from dimension-based inference. Do not upload artwork, submit a set, overwrite originals, or send private artwork to outside services without explicit authorization. If image access or a tool is unavailable, explain the limit and continue with the evidence available. Keep requirements distinct from recommendations.

Read the set plan and verify that its selected sources, order and titles are sufficiently resolved for the artist's requested output. Ask for missing decisions when necessary. Prepare a new output folder with copies of source images, named with zero-padded slot numbers and titles, preserving their file extensions; never change originals. Do not assume numbers force Studio slots: files fill empty slots in order. Warn if the draft is not empty or if numbering has gaps. Put the cover and plan/checklist outside the panel folder so only panels are dragged into Studio. Check duplicate or missing source files and filename collisions, and report unsupported or uncertain formats. Do not silently crop, resize or alter art; offer explicit opt-in transformations only if suitable tools exist. Give a Studio checklist for shape, framing review, rarity, cover and previews, and clearly state these do not transfer through bulk import. Do not submit or upload. If output exists, avoid overwriting it without permission.
